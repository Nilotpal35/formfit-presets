# Formfit exam sizes

The photo and signature sizes used by the Formfit app, as one signed file: `presets.json`.

The app downloads this file only; nothing about its users is sent or stored here. The file is made by a tool and signed, and the app ignores any copy that has been changed, so please don't edit it by hand.

Sizes are read from official notices, but notices change and can differ between posts. Always check the notice for your own exam.
